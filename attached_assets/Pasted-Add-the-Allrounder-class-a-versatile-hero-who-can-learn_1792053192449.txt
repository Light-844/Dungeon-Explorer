Add the Allrounder class, a versatile hero who can learn all skills but progresses slowly.

CLASS PROFILE:
- Name: Allrounder
- Role: Master of all trades. Slow to learn, but unstoppable once trained.
- Base Vitals: 100 HP | 60 Mana
- Attributes: STR 11 | DEX 11 | INT 11 | CON 11
- Starter Weapon: Sword
- Starter Skills: Whirlwind Strike, Fireball
- Color Theme: Silver / White

UNALLOCATED STAT POINTS (CHARACTER CREATION):
- Allrounder receives 5 unallocated stat points at creation
- Player distributes them across STR, DEX, INT, CON using +/- buttons
- Show live preview of what each point does:
  - STR: +1.2 Attack per point
  - DEX: +0.8% Crit Chance per point
  - INT: +8 Max Mana per point
  - CON: +8 Max HP and +0.8 Defense per point
- Points must all be spent before "Begin Adventure" is enabled
- Allocation is locked after the first dungeon run starts

SKILL RULES:
- Can learn ALL skills from all classes (uses canLearnSkill from the class fix)
- Learning speed is slower: every skill unlock level is multiplied by 1.5 and rounded up

  - Example: Mage learns Frost Nova at Level 3 → Allrounder learns it at Level 5
- Show the adjusted unlock level in the skill tree: "Unlocks at Level 5 (Allrounder pace)"

WEAPON RULES:
- Can equip all weapon types: Swords, Wands, Daggers, Hammers
- Other classes keep their normal weapon restrictions

- Show a small badge on the character sheet: "EXP -2% (until first title)"
